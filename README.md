- 框架：微信原生小程序

- UI：干枯玫瑰粉 #D4A0A0 + 香槟金 + 暖白底

## 快速开始

### 1. 开通云开发
开发者工具 → 工具栏「云开发」→ 开通（按量付费，免费额度足够小店使用）

### 2. 配置环境 ID
打开 `app.js`，取消第 35 行注释并填入环境 ID：
```js
wx.cloud.init({
  env: '你的环境ID',
  traceUser: true
});
```

### 3. 初始化数据库
云开发面板 → 数据库 → 创建集合：`nail_styles`, `technicians`, `service_categories`, `banners`, `activities`, `store_info`, `favorites`, `bookings`, `points`, `points_goods`, `notices`, `reviews`, `diy_works`, `admin_users`

右键 `cloudfunctions/initData/` → 上传并部署 → 云端测试

### 4. 添加管理员
在 `admin_users` 集合中新增文档，填入你的 openid 和 role: "admin"。

## 图片准备

用真实照片替换 `images/` 下各目录的占位图即可，路径和文件名无需更改。
