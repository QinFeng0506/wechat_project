将当前项目的所有改动提交存档。

## 执行步骤

### 第 1 步：确认环境
- 执行 `git status` 确认当前目录是 git 仓库
- 如果不是 git 仓库，告知用户并退出

### 第 2 步：展示待保存的文件
- 执行 `git status` 和 `git diff --stat` 展示所有改动
- 让用户了解即将存档的内容

### 第 3 步：确认存档名
- 如果用户输入了存档名，直接使用
- 如果没有提供，询问用户输入
- 存档名使用简洁的中文描述

### 第 4 步：提交
- 执行 `git add .` 暂存所有改动
- 执行 `git commit -m "存档名"` 创建存档
- 如果无改动，告知用户

### 第 5 步：总结汇报
- 显示存档名和 commit 短哈希
